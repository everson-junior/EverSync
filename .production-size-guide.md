## Resumo Executivo

| Cenário                  | Espaço Necessário | Observações                                                    |
| ------------------------ | ----------------- | -------------------------------------------------------------- |
| **Dev (máquina local)**  | 42 GB             | node_modules (6GB) + .build (12GB) + código (19MB) + resto     |
| **Produção (VM mínima)** | **3-4 GB**        | node_modules (3GB, --prod) + .next/standalone (1.2GB) + código |
| **Docker/Container**     | **1.5-2 GB**      | Apenas .next/standalone + node_modules otimizado               |

## 🎯 Para PRODUÇÃO em VM

### Opção 1: Build Standalone (Recomendado) ✅

```bash
# 1. Build otimizado
npm run build

# 2. Limpar dev deps
pnpm install --prod

# 3. Arquivos necessários em produção
# ✅ .next/standalone/  (Next.js servidor self-contained)
# ✅ node_modules/      (apenas deps de produção)
# ✅ bin/               (CLI)
# ✅ .env               (configuração)
# ❌ .build/            (não precisa mais)
# ❌ src/               (código TypeScript bruto)
# ❌ tests/             (testes)
# ❌ docs/              (documentação)

# 4. Rodar em produção
node --max-old-space-size=2048 .next/standalone/server.js
```

**Tamanho total: ~3-4 GB**

---

### Opção 2: Build Backend-Only (Se não precisa Dashboard)

```bash
npm run build:backend    # Apenas backend, sem UI

# Resulta em espaço menor:
# .next/server/ (~500MB) ao invés de .next/standalone/
# Tamanho total: ~2.5 GB
```

---

### Opção 3: Build Minimal (Mais Leve)

```bash
npm run build:basic      # OMNIROUTE_BUILD_PROFILE=minimal

# Reduz cache, i18n desnecessário, etc
# Tamanho total: ~2.5-3 GB (estimado)
```

## 🔧 Tática para VM com Espaço Limitado

### Se você tem 5GB disponível:

```bash
✅ Use opção 2 ou 3 acima
✅ Limpe .build/ após build
✅ Remova docs/, tests/, src/ após deployment
✅ Use npm ci --only=prod (mais eficiente que install)
```

### Se você tem 10GB disponível:

```bash
✅ Use opção 1 (standalone completo)
✅ Mantenha backup de src/ para rollback
✅ Limpe .build/ periodicamente
```

### Se precisa de menos ainda (~2GB):

```bash
npm run build:backend --
pnpm install --prod --no-frozen-lockfile
rm -rf .build docs tests src

# Use .next/server/ + node_modules
# Tamanho: ~2-2.5 GB
# Execução: node .next/server/index.mjs (com NODE_PATH)
```

## 📋 Checklist de Deployment

Antes de fazer deploy para produção:

```bash
# 1. Fazer build otimizado
npm run build

# 2. Instalar apenas deps de produção
rm -rf node_modules
pnpm install --prod

# 3. Verificar tamanho
du -sh .next/standalone  # deve ser ~1-1.5 GB
du -sh node_modules      # deve ser ~2-3 GB

# 4. Limpar não-necessários
rm -rf .build            # 11.7 GB economizados
rm -rf docs              # opcional
rm -rf tests             # opcional
rm -rf src               # opcional (manter backup)

# 5. Empacotar e transferir
tar -czf eversync-prod.tar.gz \
  .next/standalone \
  node_modules \
  bin \
  .env.example \
  package.json \
  pnpm-lock.yaml

# 6. Extrair na VM
tar -xzf eversync-prod.tar.gz
pnpm install --prod --offline  # se não tiver internet
```

## 💡 Dicas Extras

1. **Use `.next/standalone`** sempre que possível - é otimizado para produção
2. **Não commite .build/** no git - adicione a .gitignore (já está?)
3. **Comprima em trânsito** - use gzip para transferir (5x menor)
4. **Versione node_modules** se precisar rollback rápido
5. **Teste localmente** com `npm start` antes de enviar para VM
